# Running Guide

This document explains how to reproduce the current project progress from the cleaned repository.

## 1. Environment

Recommended:

- Python 3.9 to 3.11
- Windows PowerShell or a Unix-like shell
- Enough memory for CitiBike CSV loading if using the full raw data

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r src\bss_pipeline\requirements.txt
```

`tensorflow` is only needed for the neural-network fleet selection branch. If it is not installed, the code skips or falls back from that branch.

To enable the neural-network branch:

```powershell
pip install -r src\bss_pipeline\requirements-neural.txt
```

## 2. Run Demand Prediction + Fleet Configuration

Run with the included small sample:

```powershell
python src\bss_pipeline\bss_complete_system.py 10 --result-dir outputs\generated_bss_inputs
```

Useful options:

```powershell
python src\bss_pipeline\bss_complete_system.py 20 --csv-dir data\raw\citibike --result-dir outputs\generated_bss_inputs
python src\bss_pipeline\bss_complete_system.py 50 --disable-demand-prediction --no-neural --result-dir outputs\generated_bss_inputs
```

Expected output:

- `outputs/generated_bss_inputs/Intermodal_EGS_data_all__traditional_*.xlsx`
- `outputs/generated_bss_inputs/Intermodal_EGS_data_all__neural_*.xlsx`, only when the neural branch is enabled and configured

The generated workbook contains ALNS-compatible sheets:

- `N`: node/station list copied from the template.
- `T`: transfer node list copied from the template.
- `R`, `R_10`, `R_20`, `R_50`, `R_100`: generated orders.
- `K`: selected vehicle/fleet configuration.
- `o`: each selected vehicle's start and end depot/station.

## 3. Full Raw Data

The full files `202502-citibike-tripdata_1.csv` and `202502-citibike-tripdata_2.csv` are each larger than 100 MB, so they are not committed to GitHub. To reproduce the larger run, place them here:

```text
data/raw/citibike/
```

Then run:

```powershell
python src\bss_pipeline\bss_complete_system.py 50 --csv-dir data\raw\citibike --result-dir outputs\generated_bss_inputs
```

The sample file committed in `data/raw/citibike_sample/` is enough to verify that the pipeline works end to end.

## 4. Run ALNS Path Optimization

The ALNS script reads fixed filenames from its current working directory. Before running, copy or place the required Excel workbooks into `src/path_optimization/`:

```powershell
Copy-Item "data\alns_support\D_EGS - 10r.xlsx" src\path_optimization\
Copy-Item data\alns_support\Barge_no_land.xlsx src\path_optimization\
Copy-Item data\alns_support\Fixed_right_real.xlsx src\path_optimization\
Copy-Item data\templates\Intermodal_EGS_data_all.xlsx src\path_optimization\
```

To optimize the Excel generated by the integrated pipeline, copy it as `Intermodal_EGS_data_all.xlsx`:

```powershell
Copy-Item "outputs\generated_bss_inputs\Intermodal_EGS_data_all__traditional_YYYYMMDD_HHMMSS.xlsx" `
  src\path_optimization\Intermodal_EGS_data_all.xlsx
```

Then run:

```powershell
cd src\path_optimization
python Intermodal_ALNS_0625.py
```

Important current defaults inside `Intermodal_ALNS_0625.py`:

- `request_number_in_R = 50`, so it reads sheet `R_50`.
- `iteration_number = 200`.
- results are written to `Figures/experiment.../` and `results/`.
- entry point calls `real_main(3)`.

For faster debugging, edit `request_number_in_R` to `10` and `iteration_number` to a smaller number.
